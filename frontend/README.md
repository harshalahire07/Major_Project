# Frontend — DocVerify UI

React + TypeScript + Vite frontend for the AI Document Verification system.

## Setup

```bash
cd frontend
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Architecture

```
src/
├── components/   # Reusable UI components
├── pages/        # Page-level components
├── services/     # API client layer
├── hooks/        # Custom React hooks
└── types/        # Shared TypeScript interfaces
```
